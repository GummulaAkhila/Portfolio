# Personal Portfolio Website

## About the Project

A personal portfolio website developed to showcase my profile, technical skills, projects, education, and contact information. The website provides a simple and interactive way for recruiters and visitors to explore my work.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Responsive user interface
* About Me section
* Technical Skills section
* Projects showcase
* Education details
* Contact information
* Smooth navigation

## Project Structure

```text
Portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
```

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
